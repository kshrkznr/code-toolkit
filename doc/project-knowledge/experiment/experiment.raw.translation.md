# Translation
## Translation over invention

CTK does not introduce many new ideas.

Most of its concepts already exist somewhere:

- responsibility-driven design
- reusable configuration
- layered architecture
- documentation
- AI assistants

The interesting part is how they are arranged together.

Instead of inventing new mechanisms, CTK tries to translate between existing ones.

For example:

- VSCode configuration becomes reusable building blocks.
- Documentation becomes easier for both humans and AI to navigate.
- AI conversations become easier by sharing structured project context.

None of these are revolutionary by themselves.

They are small adjustments that reduce friction between different layers of development.

The goal is not to replace existing workflows.

The goal is to make it easier for tools, documentation, AI, and people to understand each other.

---

Translation

When exploring a new idea, prefer translating existing concepts before inventing new ones.

Many CTK concepts emerged by reinterpreting familiar ideas in a different context rather than creating entirely new abstractions.
