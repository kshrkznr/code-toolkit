# Experiment: Discussion Context Resolver

## Hypothesis

議論を始める前に Documentation Resolver でテーマ別の Inspect Summary を作ると、
AIとの議論品質が向上する。

## What to observe

- 前提を合わせるまでの時間
- 新しい概念へ到達するまでの時間
- 議論中のドキュメント参照回数
- 議論の収束性

## Current state

これはまだ仮説であり、具体的な実施例や観測結果はない。

## Boundary

この実験が観察するのは、議論前に用意するテーマ別Summaryの効果である。

[`Resolver Reading Strategy`](experiment.resolver-reading-strategy.md) は、Resolverが選んだ
文書を読者がどのように解釈するかを扱っており、この実験とは観測対象が異なる。
